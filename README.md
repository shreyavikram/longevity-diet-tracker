# Longevity Diet Tracker

A local-first nutrition tracker that runs in the browser and works offline.

**Open the app:** https://shreyavikram.github.io/longevity-diet-tracker/

On iPhone, open the link in Safari, tap Share, then Add to Home Screen. On Android, open it in Chrome and choose Install app.

There is no account or server. Tracker data is stored only in your browser. Photo, recipe, and description analysis sends the content you submit directly to Anthropic and USDA FoodData Central using API keys you enter in Settings.

This app estimates nutrition and is not medical or dietetic advice.
